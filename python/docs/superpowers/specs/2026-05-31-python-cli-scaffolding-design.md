# Python CLI Scaffolding — Design

**Status:** Draft
**Date:** 2026-05-31
**Scope:** Initial directory structure and tooling for the `crawler` Python CLI (Zego web-crawler exercise). No crawl logic yet — only the project skeleton, dev tooling, and a stub `crawl` command that demonstrates async wiring.

## Goals

- A clean, modern `src/`-layout Python package named `crawler`.
- CLI built with **Typer**, with async command bodies via **`asyncer.runnify`**.
- Tests with **pytest** + **pytest-asyncio** (auto mode).
- Format + lint via **ruff**, type-check via **ty**, everything driven by **uv**.
- A **Makefile** as the canonical task runner and a **Dockerfile** for containerised runs.
- Pinned **Python 3.13**.

## Non-goals

- No actual crawling logic. The `crawl` command is a stub that prints "not implemented".
- No CI workflow, no pre-commit hooks (explicitly out of scope per scoping decisions).
- No publishing / release tooling.

## Directory layout

```
python/
├── .dockerignore
├── .gitignore
├── .python-version           # "3.13"
├── Dockerfile
├── Makefile
├── README.md                 # already present
├── pyproject.toml
├── uv.lock                   # generated by `uv lock`
├── src/
│   └── crawler/
│       ├── __init__.py       # exposes __version__
│       ├── __main__.py       # `python -m crawler` entry
│       ├── cli.py            # Typer app + commands
│       └── py.typed          # PEP 561 marker
└── tests/
    ├── __init__.py
    ├── conftest.py
    └── test_cli.py
```

Rationale:
- `src/` layout prevents accidental imports from cwd and matches modern packaging defaults.
- `tests/` outside the package so it isn't shipped in wheels.
- `__main__.py` provides `python -m crawler` alongside the installed `crawler` script.
- `py.typed` marks the package as typed so `ty` (and downstream consumers) treat annotations as authoritative.

## `pyproject.toml` shape

Build backend: **hatchling** (uv's default).

```toml
[project]
name = "crawler"
version = "0.1.0"
description = "Single-domain web crawler CLI."
requires-python = ">=3.13"
dependencies = [
    "typer>=0.12",
    "asyncer>=0.0.7",
]

[project.scripts]
crawler = "crawler.cli:app"

[dependency-groups]
dev = [
    "pytest>=8",
    "pytest-asyncio>=0.23",
    "ruff>=0.6",
    "ty",
]

[build-system]
requires = ["hatchling"]
build-backend = "hatchling.build"

[tool.hatch.build.targets.wheel]
packages = ["src/crawler"]

[tool.ruff]
line-length = 100
target-version = "py313"
src = ["src", "tests"]

[tool.ruff.lint]
select = ["E", "F", "I", "UP", "B", "SIM"]

[tool.ruff.format]
# defaults are fine; explicit for visibility
quote-style = "double"

[tool.pytest.ini_options]
asyncio_mode = "auto"
testpaths = ["tests"]
addopts = "-ra"

[tool.ty.src]
root = "./src"
```

Notes:
- `[dependency-groups]` uses PEP 735 — `uv sync` installs dev deps by default; `uv sync --no-dev` for runtime-only (used in Docker builder stage).
- `asyncio_mode = "auto"` means any `async def test_*` runs without per-test markers.
- `ty` is still pre-1.0; the `[tool.ty.src]` block is the current way to point it at the source root. If `ty` config keys change, update here.

## CLI module (`src/crawler/cli.py`)

```python
import typer
from asyncer import runnify

app = typer.Typer(
    no_args_is_help=True,
    help="Single-domain web crawler.",
)


@app.command()
@runnify
async def crawl(
    url: str = typer.Argument(..., help="Base URL to crawl."),
) -> None:
    """Crawl URL within its own domain and print discovered links."""
    typer.echo(f"crawl: not implemented (url={url})")
    raise typer.Exit(code=1)
```

This proves: Typer app loads, `asyncer.runnify` wraps the async command correctly, and the test framework runs.

## Makefile

```make
.PHONY: install fix format-check lint typecheck test check run clean docker-build docker-run

ARGS ?=

install:
	uv sync

fix:
	uv run ruff format .
	uv run ruff check . --fix
	uv run ruff format .

format-check:
	uv run ruff format --check .

lint:
	uv run ruff check .

typecheck:
	uv run ty check

test:
	uv run pytest

check: format-check lint typecheck test

run:
	uv run crawler $(ARGS)

clean:
	rm -rf .venv .pytest_cache .ruff_cache dist build *.egg-info

docker-build:
	docker build -t crawler:dev .

docker-run:
	docker run --rm crawler:dev $(ARGS)
```

`make run ARGS="crawl https://example.com"` is the canonical local invocation.

`make fix` applies ruff format, then ruff lint auto-fixes (which can reorder imports via the `I` rule), then re-runs format so any reordering ends up correctly formatted. `make check` is the verify-only counterpart — non-mutating and suitable for CI.

## Dockerfile

Multi-stage, uv-based:

```dockerfile
# syntax=docker/dockerfile:1.7

FROM ghcr.io/astral-sh/uv:python3.13-bookworm-slim AS builder
WORKDIR /app
ENV UV_LINK_MODE=copy \
    UV_COMPILE_BYTECODE=1 \
    UV_PROJECT_ENVIRONMENT=/app/.venv

COPY pyproject.toml uv.lock ./
RUN --mount=type=cache,target=/root/.cache/uv \
    uv sync --frozen --no-dev --no-install-project

COPY src ./src
RUN --mount=type=cache,target=/root/.cache/uv \
    uv sync --frozen --no-dev

FROM python:3.13-slim AS runtime
WORKDIR /app
RUN useradd --create-home --uid 1001 app
COPY --from=builder --chown=app:app /app/.venv /app/.venv
COPY --from=builder --chown=app:app /app/src /app/src
ENV PATH="/app/.venv/bin:$PATH"
USER app
ENTRYPOINT ["crawler"]
CMD ["--help"]
```

`.dockerignore` excludes `.venv`, `.git`, `tests`, `__pycache__`, `.pytest_cache`, `.ruff_cache`, `docs`.

## `.gitignore`

Standard Python + uv + IDE entries: `.venv/`, `__pycache__/`, `*.pyc`, `dist/`, `build/`, `*.egg-info/`, `.pytest_cache/`, `.ruff_cache/`, `.mypy_cache/`, `.coverage`, `htmlcov/`, `.idea/`, `.vscode/`.

## Verification

Once scaffolded, all of these must succeed from `python/`:

1. `uv sync` — installs runtime + dev groups, creates `.venv` and `uv.lock`.
2. `make check` — runs `format-check`, `lint`, `typecheck`, `test`; all pass.
3. `make run ARGS="--help"` — prints Typer help, exits 0.
4. `make run ARGS="crawl https://example.com"` — prints "not implemented", exits 1.
5. `make docker-build && make docker-run ARGS="--help"` — container builds and prints help.

Only when all five pass is the scaffolding task complete.
