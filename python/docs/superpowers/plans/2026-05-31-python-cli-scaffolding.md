# Python CLI Scaffolding Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stand up the `crawler` Python CLI skeleton — package layout, tooling (uv / ruff / ty / pytest), Makefile, Dockerfile, and a stub `crawl` command — so that future work can drop the real crawler logic into a working dev environment.

**Architecture:** `src/` layout single package. Typer app exposed as both the `crawler` console script and `python -m crawler`. Async command bodies wired through `asyncer.runnify`. `uv` is the single entry point for installing, running, testing, linting, and type-checking. A multi-stage uv-based Dockerfile produces a small non-root runtime image.

**Tech Stack:** Python 3.13, uv, Typer, asyncer, pytest + pytest-asyncio (auto mode), ruff (format + lint), ty (type check), hatchling (build backend), Docker (multi-stage).

**Working directory for all commands and paths:** `/Users/febus982/github/febus982/engineer-hiring-tech-exercise/python`

- [ ] **Step 4: Implement `cli.py`**

Create file `python/src/crawler/cli.py` with this exact content:

```python
import typer
from asyncer import runnify

app = typer.Typer(
    no_args_is_help=True,
    help="Single-domain web crawler.",
)


@app.command()
@runnify
async def crawl(
    url: str = typer.Argument(..., help="Base URL to crawl."),
) -> None:
    """Crawl URL within its own domain and print discovered links."""
    typer.echo(f"crawl: not implemented (url={url})")
    raise typer.Exit(code=1)
```

- [ ] **Step 5: Run the tests and watch them pass**

Run: `uv run pytest tests/test_cli.py -v`
Expected: both tests pass.

If `test_crawl_stub_...` fails because `result.exit_code` is `0` instead of `1`, the most likely cause is that `runnify` swallowed the `typer.Exit`. Verify the `@runnify` decorator wraps the function correctly (it must be the innermost decorator below `@app.command()`). If asyncer's API differs (e.g. the function is named differently in your installed version), check `python -c "import asyncer; print(dir(asyncer))"` to find the correct exported name.

- [ ] **Step 2: Create the Dockerfile**

Create file `python/Dockerfile` with this content:

```dockerfile
# syntax=docker/dockerfile:1.7

FROM ghcr.io/astral-sh/uv:python3.13-bookworm-slim AS builder
WORKDIR /app
ENV UV_LINK_MODE=copy \
    UV_COMPILE_BYTECODE=1 \
    UV_PROJECT_ENVIRONMENT=/app/.venv

COPY pyproject.toml uv.lock ./
RUN --mount=type=cache,target=/root/.cache/uv \
    uv sync --frozen --no-dev --no-install-project

COPY src ./src
RUN --mount=type=cache,target=/root/.cache/uv \
    uv sync --frozen --no-dev

FROM python:3.13-slim AS runtime
WORKDIR /app
RUN useradd --create-home --uid 1001 app
COPY --from=builder --chown=app:app /app/.venv /app/.venv
COPY --from=builder --chown=app:app /app/src /app/src
ENV PATH="/app/.venv/bin:$PATH"
USER app
ENTRYPOINT ["crawler"]
CMD ["--help"]
```
